# Curriculum Editor Override

The product brief overrides the generated blue recommendation with an education-oriented emerald accent. Keep the neutral slate surfaces, compact dashboard density, system Segoe UI stack, and restrained motion.

- Primary: emerald 700; hover: emerald 800; focus ring: emerald 700.
- Status meaning always includes text, not color alone.
- Desktop/tablet: dense spreadsheet with sticky header and stable-ID column.
- Phone: card-based row editor with 44px controls and no page-wide horizontal overflow.
- Motion: only 150ms button/state transitions; no entrance choreography for frequently changing grid rows.
- Accessibility: visible labels, skip link, sortable-header `aria-sort`, keyboard cell navigation, reduced-motion support, and 16px mobile inputs.
